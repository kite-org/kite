# Internationalization

Kite supports English and Chinese, and plugins share this capability through the SDK's i18n utilities. Plugin dictionaries are isolated from Kite's own translations. When users change Kite's language, plugin text changes with it.

## Dictionary Files

Store translations in `src/locales/en.json` and `src/locales/zh.json`. Both files must have **exactly the same key structure**. Build validation rejects dictionaries with mismatched keys:

```json
{
  "navigation": {
    "workloads": "Workload Tools",
    "deployment": "Deployment"
  },
  "actions": {
    "refresh": "Refresh {{name}}"
  }
}
```

## Bind the Dictionaries

Bind the dictionaries once in `src/i18n.ts`:

```ts
import { createPluginI18n } from '@kite-dev/plugin-sdk/i18n'

import en from './locales/en.json'
import zh from './locales/zh.json'

export const {
  resources: translations,
  label,
  useTranslation,
} = createPluginI18n({ en, zh })
```

`createPluginI18n` provides two ways to consume translations:

- **`label(key)`**: use this for route titles and menu labels in `plugin.config.tsx`. It returns all translations for a key as data without selecting a language. The SDK writes these translations into `plugin.json`, allowing Kite to translate sidebar menus **without loading the plugin's JavaScript**.
- **`useTranslation()`**: use this in page components to resolve keys in the current language.

## Use label in Configuration

```tsx
export default definePlugin({
  i18n: translations,
  routes: [
    { id: 'workloads', path: '', title: label('navigation.workloads'), element: <WorkloadsPage /> },
  ],
  menus: [
    { id: 'workloads', label: label('navigation.workloads'), route: 'workloads' },
  ],
})
```

## Use t in Pages

Import `useTranslation` from your local `src/i18n.ts` in page components:

```tsx
import { Button } from '@kite-dev/plugin-sdk/ui'

import { useTranslation } from '../i18n'

export function RefreshButton({ name, onClick }: { name: string; onClick: () => void }) {
  const { t } = useTranslation()
  return <Button onClick={onClick}>{t('actions.refresh', { name })}</Button>
}
```

- Keys passed to `t('key')` have TypeScript autocompletion.
- Use `t('key', { name })` to interpolate `{{name}}` in a message. i18next plural syntax is also supported.
- The hook also returns `language`, such as `zh` or `en`, for localized date and number formatting.

## Behavior

- Page translations load with the plugin. You do not need to register a namespace manually. Kite removes the dictionaries when the plugin is disabled.
- Translation keys must exist in both `en.json` and `zh.json`, with matching structures at every nesting level, or the build fails.
- Missing translations display the raw key, such as `actions.refresh`, without throwing a runtime error.
